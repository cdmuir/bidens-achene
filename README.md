# Evolutionary Reversibility and the Island Syndrome: Breaking the One-Way Street of Dispersal Loss

Code and data for the phylogenetic analyses of achene (fruit) traits in Hawaiian *Bidens*, supporting the manuscript above.

## Authors

Matthew L. Knope, Luke C. Campillo, Kasey E. Barton, Ashlyn Bazzel, Brannan R. Cliver, Daniel S. Jones, Nathaniel Kingsley, Erika Lesperance, Clifford Morden, Christopher D. Muir, Jena Osmani, Jonathan Price, Lizzie Roeble, Emily Saling, Robert C. Thomson, Dustin Wolkis, Mitsuko Yorkston

## Repository structure

```
data/    Achene trait measurements and a sample of 100 posterior trees
r/       Analysis scripts, run in order
objects/ Intermediate and final results (.rds), generated by the scripts
```

### Data

- `data/bidens_achene.csv` — achene trait measurements (length, width, mass, presence of awn, pubescence, shape, wing state) and elevation covariates for each taxon.
- `data/sampled_100_trees.nex` — 100 trees sampled from the posterior distribution of a phylogeny, used to account for phylogenetic uncertainty.

### Scripts (`r/`)

Run in order; each sources `header.R` to load required packages.

1. `01_prepare-data.R` — reads in the trees and trait data, drops outgroup taxa, log-transforms continuous traits, and scales elevation covariates. Saves prepared data to `objects/prepared-data.rds`.
2. `02_fit-pglmm.R` — fits phylogenetic generalized linear mixed models (`phyr::pglmm`) for each combination of response trait and predictor, across all 100 trees, and generates bootstrap predictions via simulation. Saves results to `objects/pglmm-results.rds`.
3. `03_summarize-results.R` — summarizes model results (mean ΔAIC, bootstrap confidence intervals, probability of direction, and bootstrap p-values) across trees.
